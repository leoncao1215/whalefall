# 评测

没有评测的记忆系统 = 没有记忆。

## 文件

- `questions.jsonl`：一行一题。当前是 10 条**示例**（P3 前补到 30 条，并且必须替换成真实历史）。
- `report.md`：每次跑完记录结果（P3 起生成）。

字段：

| 字段 | 含义 |
| --- | --- |
| `id` | 唯一编号 |
| `question` | 用户会怎么问（口语、模糊，不要写得太规整） |
| `kinds` | 预期命中的事件类型，空数组表示不限 |
| `expected_contains` | 期望出现在召回结果里的关键词；空数组表示人工判定 |
| `notes` | 这道题在考什么 |

## 指标（P3 起）

- **recall@5**：正确答案是否出现在前 5 条召回里。
- **层级命中**：该由摘要回答的题（如 q004），是否停在了摘要层而没有把原文全捞出来。
- **平均耗时**：单次检索 p50 / p95。
- **token 成本**：一次问答注入的上下文 token 数。

## 原则

1. 题目用**真实口吻**写，允许"那个东西""上次"这种指代。
2. 每道题都要能人工判断对错，不要写"总结一下我的人生"。
3. 加新功能前先跑一遍基线；跑不过就是退步。
